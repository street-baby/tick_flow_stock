# 云之心量化项目讲解视频设计

日期：2026-08-30

## 1. 目标

制作一支约 7 分钟的中文项目讲解视频，通过真实操作当前运行的“云之心量化”界面，完整说明项目的用途、主要模块、核心工作流和风险边界。

视频需要同时满足三种用途：

- 用户自己学习项目操作；
- 向其他人展示项目能力；
- 发布到 B 站、抖音等平台进行专业介绍。

视频定位为实战教学录屏，不制作成纯宣传片。观众看完后应当能够理解“数据从哪里来、如何选股、如何回测、如何形成交易计划”，但不应产生系统可以保证收益或已经实现券商自动下单的误解。

## 2. 受众与输出

### 2.1 目标受众

- 想了解个人量化交易工作台的投资者；
- 希望学习项目操作的当前用户；
- 对选股、回测、监控和交易计划感兴趣的内容平台观众。

### 2.2 输出规格

- 主视频：`1920x1080`、`30fps`、`16:9`、H.264 MP4；
- 主视频路径：`output/video/yunzhixin-quant-project-tour.mp4`；
- 附加输出：无字幕纯净版、中文字幕文件、封面图；
- 保留讲解脚本、字幕时间轴和可重新渲染的工程文件。

## 3. 内容结构

目标总时长约 7 分钟，允许根据真实页面加载和讲解节奏在 6–8 分钟之间调整。

| 时间 | 章节 | 主要内容 |
| --- | --- | --- |
| 00:00–00:18 | 片头 | 云之心量化名称、金融终端画面、项目一句话定位 |
| 00:18–00:55 | 市场总览 | 首页总览、核心指标、A 股/港股/美股切换 |
| 00:55–01:35 | 数据能力 | 数据源、行情同步、日线与分钟数据、指标流水线 |
| 01:35–02:25 | 市场研究 | 指数、概念、行业、财务和个股分析 |
| 02:25–03:20 | 策略选股 | 策略列表、筛选参数、候选结果与评分解释 |
| 03:20–04:20 | 回测验证 | 回测参数、收益曲线、回撤、交易明细和结果边界 |
| 04:20–05:05 | 监控执行 | 自选股、监控规则、提醒和盘中使用方式 |
| 05:05–06:25 | 实战工具 | 交易计划、尾盘选股、竞价抢筹、暗盘资金 |
| 06:25–06:50 | 风险边界 | 回测不代表未来、暗盘指标口径、非自动下单系统 |
| 06:50–07:05 | 片尾 | 工作流总结、品牌收束 |

页面覆盖以“完整介绍所有一级功能，重点演示核心闭环”为原则。市场总览、策略、回测、监控和交易计划需要展示实际操作；低频设置页和相似分析页可以通过快速导航与旁白概括，避免为了逐页停留而拖慢节奏。

## 4. 叙事方式

视频以以下工作流作为主线：

```text
行情数据 -> 指标加工 -> 市场判断 -> 策略选股
         -> 历史回测 -> 交易计划 -> 盘中监控 -> 复盘
```

每个章节都回答三个问题：

1. 这个页面解决什么问题；
2. 用户需要进行什么操作；
3. 页面结果应该如何理解，不能如何误用。

旁白采用沉稳专业男声，语速约每分钟 220–250 字。讲解优先使用日常中文，不堆叠技术名词；必须出现的金融指标在画面中同步显示名称和单位。

## 5. 视觉与声音

### 5.1 视觉方向

采用“实战教学录屏”方向：

- 真实项目界面是画面主体；
- 保持当前金融终端配色与界面结构；
- 使用冷青色描边标出当前操作区域；
- 关键步骤显示编号、简短动作提示和参数解释；
- 必要时对表格、图表和参数面板做局部放大；
- 鼠标移动保持平稳，点击后给界面充分响应时间；
- 片头和片尾保留轻量品牌动画，中段不增加抢占内容的装饰。

不使用厚重视频边框、持续发光、密集粒子或大面积赛博朋克装饰。动态效果服务于操作理解，不改变或遮挡项目界面。

### 5.2 字幕

- 主视频使用底部双行中文字幕；
- 重要参数、章节标题和风险提示使用独立画面标注；
- 字幕不能遮挡表格分页、弹窗按钮、K 线时间轴和页面底部操作区；
- 金融术语、单位和百分比必须与界面口径一致；
- 另行输出可编辑字幕文件。

### 5.3 音频

- 配音：沉稳专业中文男声；
- 背景音乐：低音量电子金融氛围，主要用于片头、章节过渡和片尾；
- 中段讲解以人声清晰度为最高优先级；
- 点击、切换和重点标注可以使用克制的提示音，不连续堆叠音效。

## 6. 录制范围与操作约束

录制目标为 `http://localhost:3011/` 当前真实项目，并使用独立浏览器会话执行操作。

录制前检查：

- 前端与后端健康状态；
- 每个计划录制页面的加载、空数据和错误状态；
- 需要遮挡的账户、持仓、参数和凭据区域；
- 图表动画和接口加载的稳定性；
- 录制分辨率下侧栏、弹窗和表格是否完整可见。

录制期间允许：

- 页面导航、市场切换和标签切换；
- 查看现有数据、策略结果、回测结果和监控配置；
- 使用可重复的演示参数运行不会破坏用户数据的查询或计算。

录制期间禁止：

- 删除或覆盖策略；
- 修改或清空数据源凭据；
- 清空行情数据、历史记录或持仓；
- 执行不可恢复的配置变更；
- 为了画面效果伪造收益、成交或资金流数据。

## 7. 脱敏方案

第一阶段录制真实界面，后期再逐项确认和遮挡。默认需要检查：

- API Key、Token、Webhook 和登录信息；
- 账户金额、持仓数量、成本价和盈亏；
- 用户不希望公开的策略参数、策略代码和选股结果；
- 本地路径、个人名称和其他身份信息。

遮挡采用跟踪马赛克或不透明信息块，不能用低强度模糊导致内容仍可恢复辨认。成片导出前进行一次全片敏感信息复查。

## 8. 金融口径与风险表达

- 不使用“稳赢”“保证盈利”“胜率必然达到某值”等表述；
- 回测章节明确提示“历史回测不代表未来收益”；
- 收益率、回撤、胜率和交易成本必须以界面实际值为准；
- 暗盘资金页面明确说明其结果是基于量价、换手和背离关系推算的资金行为指标，不是交易所或券商提供的真实暗盘成交数据；
- 交易计划页面说明当前系统用于辅助决策、仓位和风险管理，不等同于已经接入券商的全自动交易系统；
- 港股、美股免费数据可能存在延迟或缺失，涉及相关画面时保留数据限制说明。

## 9. 制作流水线

1. 检查本地服务和全部目标页面；
2. 建立录制清单与敏感信息清单；
3. 根据章节结构编写逐句旁白和操作脚本；
4. 使用浏览器自动化与人工视觉检查完成逐段录制；
5. 整理录屏素材，移除等待、误点和无效加载片段；
6. 生成男声配音与字幕时间轴；
7. 合成片头、录屏、章节标题、局部标注、字幕、音乐和片尾；
8. 渲染审阅版，完成内容、画面、音频和脱敏检查；
9. 根据检查结果修订并导出最终视频及附加文件。

若某个页面在录制时无数据、接口失败或权限不足，优先展示真实状态并解释原因。只有不影响事实表达时，才可以改用此前已经验证的真实截图；不得用虚构数据替代失败页面。

## 10. 验收标准

### 10.1 内容

- 覆盖数据、分析、策略、回测、监控和实战工具的完整闭环；
- 每个重点页面说明用途、操作和结果含义；
- 项目定位、数据限制和交易边界表述准确；
- 不包含未经证据支持的盈利承诺。

### 10.2 画面

- 成片为 1080p，项目界面无空白、错位或非预期弹窗；
- 字幕、鼠标、标注和界面元素之间无明显遮挡；
- 局部放大后文字和图表保持清晰；
- 无密钥、账户和其他敏感信息泄露；
- 章节过渡与真实页面操作连续，不造成操作顺序误解。

### 10.3 音频

- 配音清晰，无明显错字、断句或金融术语误读；
- 字幕与配音、操作画面基本同步；
- 背景音乐不掩盖人声；
- 章节之间响度稳定，无明显爆音或突变。

### 10.4 技术验证

- 最终 MP4 可在常用播放器中完整播放；
- 视频时长处于 6–8 分钟范围；
- 视频与音频编码兼容常见内容平台；
- 抽查开头、中段、片尾和所有遮挡片段的渲染结果；
- 保留字幕、封面和可重新渲染的源工程。

## 11. 非目标

- 不在本次任务中开发新的项目功能；
- 不修改策略、回测或数据源业务逻辑；
- 不接入券商交易接口；
- 不制作针对单一短视频平台的竖屏重剪版；
- 不把项目包装成投资建议或收益保证工具。
